scope: dungeon & dragons

Goal: to have an initiative/effect tracking dashboard.

1. I want to be able to manually list an unlimited number of creatures/PCs/NPCs. This involves a category for their name and the initiative number they have rolled.

2. Once I’ve entered the names and initiative rolls, I should be able to sort them from highest to lowest at any time. I want to also add as needed as more creatures may arrive to the encounter.

3. The creature whose turn it is should be highlighted until I press a button to advance to the next creature on the initiative tree.

4. There should be an auto round tracker that is easily seen. So, when combat begins, and all rolls have been made and sorted, the round tracker should say “Round 1.” After I advance the list back to the top, the tracker should advance to “Round 2” and so on.

5. When I click on a player or creature on the initiative list, I want something to pop up that will allow me to enter the name of an effect and how many rounds it lasts. As I advance through each listed player/creature on the initiative list, a fixed box off to the right of the initiative list will display what current effects are on that creature and how many turns are left on any effect that is on them. When I advance to a new round, the effects that are listed for any creature on the list will lessen by 1. When the number reaches 0, the effect will disappear completely from the list.

6. I’d like a third editable window below the initiative window that lets me add loose dm notes about anything I need.

7. Could you make a fourth window with random dice rolls for d4, d3, d6, d8, d10, d12, and d100? It’s important that I can specify a number of dice and the modifier that would modify each of those dice. For example, I might want to roll four d20 with a +2 modifier on each die, then sum them.

8. I want to be able to save an "encounter" to bring up later. In other words I want to be able to save multiple encounter files.
